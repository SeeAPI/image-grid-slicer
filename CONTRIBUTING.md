# Contributing

Thanks for helping improve Image Grid Slicer.

1. Fork the repository and create a focused branch.
2. Run `npm install` and `npm run dev`.
3. Keep the core browser-native and avoid server-only dependencies.
4. Run `npm run typecheck` and `npm run build` before opening a pull request.
5. Explain user-facing changes and include screenshots when the editor UI changes.

Please open an issue before starting a large API or interaction redesign.
